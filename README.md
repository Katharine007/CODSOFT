## 📌 Internship Highlights

During the internship, we were required to complete **three out of four tasks**. I completed the following projects:

### ✅ Task 2 – Basic Calculator
A simple yet functional calculator that performs basic arithmetic operations such as:
- Addition
- Subtraction
- Multiplication
- Division

Built using: `HTML`, `CSS`, and `JavaScript`

---

### ✅ Task 3 – PassWorld: Password Generator Web App
A secure password generator web application that:
- Generates strong random passwords
- Allows user customization (length, character types)
- Frontend: `HTML/CSS`
- Backend: `Python` and `Flask`

---

### ✅ Task 4 – Nostalgia: Rock, Paper, Scissors Game
A fun GUI-based game where the user can play Rock, Paper, Scissors against the computer.

Built using:
- `Python`
- `Tkinter` for the GUI
